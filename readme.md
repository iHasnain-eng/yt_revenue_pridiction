# YouTube Revenue Prediction 📊

## Project Overview

This project analyzes YouTube channel data and predicts channel revenue using Machine Learning.

The dataset contains:

- Subscribers
- Views
- Videos
- Watch Time
- Revenue

## Technologies Used

- Python
- Pandas
- Scikit-Learn
- Linear Regression

## Project Workflow

1. Load Dataset
2. Data Cleaning
3. Handle Missing Values
4. Data Analysis
5. Feature Engineering
6. Train Machine Learning Model
7. Revenue Prediction

## Features

- Missing value handling
- Revenue status classification
- Revenue prediction using ML
- Data analysis with Pandas

## Machine Learning Model

Model Used:

- Linear Regression

Model Score:

- R² Score: 0.87

## Files

- main.py → Data Cleaning & Analysis
- ml.py → Machine Learning Model
- youtube_dataset.csv → Dataset
